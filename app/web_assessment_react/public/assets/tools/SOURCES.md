# Assessment application artwork

These files identify third-party applications used inside Valases-managed assessment sessions. They are not part of the Valases brand and do not imply vendor endorsement.

- `excel-official.svg`: Microsoft Excel icon authored by Microsoft, obtained from the current Microsoft 365 artwork mirrored on Wikimedia Commons. Source: https://commons.wikimedia.org/wiki/File%3AMicrosoft_Office_Excel_%282025%E2%80%93present%29.svg
- `vscode.png`: Visual Studio Code stable icon from Microsoft's brand resource. Source: https://code.visualstudio.com/brand
- `quickbooks-official.svg`: QuickBooks product glyph from Simple Icons, whose listed source is the QuickBooks design system. Source: https://simpleicons.org/?q=quickbooks and https://designsystem.quickbooks.com/visual-assets/logos/
- `drake-tax.png`: Drake Tax wordmark from Drake Software's knowledge base. Source: https://kb.drakesoftware.com/kb/Drake-Tax/11506.htm

Product names, icons, and trademarks belong to their respective owners. Keep the artwork unmodified and obtain any required vendor approval before commercial launch.
